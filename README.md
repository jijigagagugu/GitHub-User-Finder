# GitHub User Finder

## Автор
Бахматов Александр

## Описание
Это простое GUI-приложение для поиска пользователей GitHub по имени. Пользователи можно добавлять в список избранных, который сохраняется в локальном JSON-файле.

## Использование API
Пользователь вводит имя пользователя в поле поиска и нажимает кнопку "Поиск пользователя". Если пользователь найден, его имя отображается. Можно добавить его в избранные, нажав соответствующую кнопку.

## Примеры использования
- Введите `octocat` и нажмите "Поиск пользователя"
- Нажмите "Добавить в избранное", чтобы сохранить его
- Посмотреть список избранных ниже
